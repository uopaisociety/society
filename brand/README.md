## Logo

![AI Society. The stacked AI Society wave mark in marine navy on a transparent background.](logo.svg)

- **File:** [logo.svg](logo.svg)
- **Dimensions:** 1080 × 1080
- **viewBox:** `0 0 1080 1080`
